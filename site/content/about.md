# About this site

Was the Bus On Time? is an unofficial project. It is not affiliated with, endorsed by, or operated by Intercity Transit or Sound Transit. Intercity Transit has not reviewed or approved anything on this site.

## What it is

An independent, open-source project that measures how often Intercity Transit buses leave their stops on time. Intercity Transit is headquartered in Olympia, Washington, and serves a [Public Transportation Benefit Area (PTBA)](https://gis-intercitytransit.hub.arcgis.com/datasets/d5f34e2925c441aba160994c57fd3c8f_0/explore?location=47.019650%2C-122.784469%2C11) in Thurston County. This project records the agency's public real-time data, compares each departure with the published schedule, and publishes the results as statistics by route, stop, hour and day.

## What it isn't

- Not a trip planner, and not a source of real-time arrival information. For trip planning and live bus times, use Intercity Transit's own tools.
- Not the agency's official performance report. The numbers here are computed independently and may differ from the agency's own figures. See [Methodology](/methodology/).

## How AI was used

The code and the text of this site were written with help from an AI assistant. A person reviewed all of it before publication.

The statistics themselves are computed by ordinary, deterministic code from the agency's public data. No AI model produces, estimates or adjusts any number on this site.
