Title: Privacy

# Privacy

- **No cookies.** This site sets no cookies and has no accounts, forms or comments.
- **Analytics.** Visits are counted with Cloudflare Web Analytics, which is cookieless and reports only aggregate figures such as page views. It does not fingerprint visitors.
- **Hosting.** Cloudflare (which serves the site) and GitHub (which hosts the code and data repositories) see visitors' IP addresses as part of delivering pages and files.
- **Country.** The country of your IP address is used only to decide whether the site is available in your region. It is not stored by us.
- **Email.** If you email us, your message is kept only so we can reply.
